Bindarr Import Companion

Paste a TCGplayer export, a decklist (precon, Moxfield, MTGGoldfish), or a ManaBox list. It rewrites every line into the text format Bindarr's Settings → Import Backup reads: qty Name (SET) number, plus *F* for foil.

1 · Paste the list

2 Zahur, Glory's Past (Borderless) [DFT] 370
Decklist / precon
1 Arcane Signet — set the default set below
ManaBox / Moxfield
1 Spell Pierce (DFT) 64 *F*

The list above is example data. Replace it with your own. Section headers like "Commander" or "Sideboard" are skipped.

Precons: use the commander set's code (Edge of Eternities Commander is EOC). Cards not found in that set fall back to any printing and get flagged. Set code fixes map TCGplayer-only codes to Scryfall codes.

QtyCardSet · No.FoilStatusNoteOriginal line

Tick Foil for foils. TCGplayer's export doesn't mark them, so check the physical cards. Amber rows were matched to a different printing than the line asked for; confirm them before importing.

3 · Copy into Bindarr

Save it as a .txt file and import it once. Bindarr adds every line as new copies, so importing the same list twice doubles the cards. Red rows are left out of this text; add those cards by hand.
